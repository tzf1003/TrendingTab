# AI 与提醒

Pi 运行时通过以下协议处理模型请求和流式事件：

| 协议 | 相对路径 |
|---|---|
| OpenAI Responses | `responses` |
| OpenAI Chat Completions | `chat/completions` |
| Anthropic Messages | `messages` |

API 根地址按相对路径拼接。凭据保存在 Keychain，配置导出不包含密钥。OpenAI 请求在支持时设置 `store: false`。

在“设置 → AI 分析”中可编辑已保存连接的协议、地址、模型和请求参数，也可单独更新 API Key。编辑后原有任务分配保持不变；与自动任务相关的配置变化会触发当前热点的重新评估，并继续遵守预算。

事件中心由热点列表、内置浏览器和右侧 AI 对话栏组成。点击热点会在中栏打开原文。可在应用内登录站点；用户页面和 AI 页面共享应用的网站数据，登出或清除站点数据会影响该站点的所有标签。应用内登录状态与 Chrome、Safari 的登录状态分别保存。

右侧可选择直接回答或深度研究。深度研究可查看当前有效榜单、使用 AI 标签、网页搜索或配置的 Brave、Tavily 搜索服务，并通过应用登记的证据编号引用来源。榜单标题和搜索摘要分别标明材料类型；阅读正文后可进一步核对。读取或操作用户当前标签需要本轮授权，可选择仅允许读取、允许操作、拒绝或让 AI 在独立标签打开页面。用户在网页内操作、切换标签或页面导航时，该授权失效；具体按钮和表单操作还需逐次确认。遇到登录或验证时可接管页面，完成后继续研究。MCP 服务在设置中添加并选择启用的工具，每次调用都需要确认。网页内容和外部工具结果作为引用材料处理；发送给模型的内容取决于本次研究使用的材料和工具结果。

对话方式会保存为应用偏好。选择 AI 标签可预览研究进度，AI 仍可读取和操作该页面；点击“接管此页面”、使用导航控件或直接操作网页后，页面转由用户控制，待确认操作立即关闭。同一新闻对话的后续提问可复用已有 AI 页面，并重新观察以取得本轮操作标识。结束对话后清除页面归属与研究材料，其他新闻对话独立使用自己的页面。

深度研究可向上或向下滚动 AI 页面，支持整页及正文内层滚动区域，用于读取后续和懒加载内容。滚动保持用户页面及当前选中标签，随后重新观察或读取正文；旧页面元素标识立即失效。用户接管、页面导航变化或任务结束后，原任务不能继续滚动该页面。直接回答使用已有材料；需要页面操作时请选择深度研究。

每条 AI 回答按收到文本时可用的证据编号校验引用。回答结束或停止后，该范围保持不变；后续研究新增的证据可用于新回答，不能使旧回答的未知编号自动变为有效来源。材料仍按新闻对话隔离，来源按钮显示材料类型和获取时间。

搜索工具通过 `topic` 选择 `general`（默认）或 `news`。新闻模式使用 [Brave 新闻端点](https://api-dashboard.search.brave.com/api-reference/news/news_search/get)或 [Tavily 的 news 模式](https://docs.tavily.com/documentation/api-reference/endpoint/search)，并保留时间与站点范围。未配置 API 时继续使用所选网页引擎的通用搜索，并在工具结果中注明。结果摘要与实际读取的页面正文分别登记证据，发布时间按供应方提供的信息展示。Runtime 0.1.5 包含这一工具参数，需要应用 0.2.44 及以上版本。

浏览器正文提取优先选择网页主内容，排除导航、表单和可编辑区域，也会忽略未显示的文字。网页以普通正文展示的信息仍可能包含个人或敏感内容，应用无法可靠识别所有这类内容；授权读取页面时请确认适合发送给所选模型服务。

公开网页也可通过独立的匿名连接读取并分段引用。此方式固定经过校验的公网 IPv4 地址，不自动跟随重定向；仅提供 IPv6 的网站、需要登录的页面或返回重定向的链接可使用 AI 浏览器标签阅读。匿名读取不使用应用内的网站登录状态。

AI 可以观察研究标签中的同站表单按钮和普通网页按钮并申请执行。确认卡显示按钮、页面、目标和可见表单字段；确认只对当前任务及页面快照有效，执行前会再次核对页面内容和按钮身份。GET 与 URL 编码的 POST 表单导航还会核对实际提交字段；字段变化、请求体不可读取或使用其他 POST 编码时需要用户接管。包含密码、文件、信用卡字段或多选列表的表单需要用户接管。网页中其他被拦截的表单导航也会转交用户处理。网页按钮的具体行为由网站脚本决定，触发操作后应核对结果；网站脚本发起的后台网络请求不经过 WebKit 的导航回调，这项机制不能覆盖网页的所有后台行为。

研究页面遇到 HTTP 401、403 时会提示用户查看登录或访问限制；HTTP 429 和其他错误响应会显示对应状态。错误页不会作为网页正文登记证据，子框架的失败不会覆盖主页面状态。

AI 标签的顶层导航会拒绝本机名称、局域网名称和 IP 字面量，重定向时也会检查目标地址。此检查不控制 WebKit 对域名的 DNS 解析，也不限制页面脚本发起的后台连接；它并不能保证隔离本机网络，或保证所有站点操作都先经过确认。这两项能力仍需进一步实现和验收。

WebKit 的导航代理用于决定导航请求；`WKURLSchemeHandler` 不能注册 WebKit 已处理的 `https` 等协议，因此不能把它当作所有网页请求的拦截器。相关系统接口见 [Apple 的导航代理说明](https://developer.apple.com/documentation/webkit/wknavigationdelegate/webview%28_%3Adecidepolicyfor%3Apreferences%3Adecisionhandler%3A%29)和[自定义 URL scheme 说明](https://developer.apple.com/documentation/webkit/wkwebviewconfiguration/seturlschemehandler%28_%3Aforurlscheme%3A%29)。

会话按新闻 ID 隔离，切换新闻可继续原来的对话。停止生成会取消请求并保留已收到的文字；重试替换该次回答，后续提问携带已有对话。会话仅保存在内存中，结束对话、关闭事件中心或退出应用后清理；掉榜不会中断正在阅读的页面或研究。流式错误、回答截断和空响应会显示重试入口。自动 AI 预算与用户主动发起的对话分别处理。

自动分析默认每天 100 次、100,000 tokens。请求先持久化预留；结果未知时保守记账且不自动重发。在“设置 → AI 分析”中可选择允许重新分析，原有用量记录会保留，新的请求仍受预算限制。模型输出必须是 JSON，未知证据 ID 会被拒绝。

“自动摘要读取公开原文”默认关闭。开启后，重大事件摘要最多匿名读取 3 篇报道，每篇使用最多 6,000 字正文摘录，与标题和已有摘要一起交给 Pi 的摘要模型。该读取使用独立匿名连接；需要应用内登录身份的阅读可在右侧深度研究中进行。原文无法读取时使用标题和已有摘要，并标明实际材料范围。正文摘录仅保留在本轮内存中，生成的摘要、材料级别和用量按自动任务规则保存。

原文读取前检查自动预算，模型请求前再按实际输入预留用量。读取期间关闭分析、修改摘要配置或材料过期后，旧材料不会发往模型。切换原文读取设置会重新生成当前重大事件摘要，并继续遵守每日预算；结果未知的相同请求保持去重。

模型 API Key、自定义请求头和 MCP 凭据保存在 Keychain。右侧对话逐次记录模型请求的用量；供应商未提供用量或请求中断时显示估算值。估算包含当次上下文、工具定义和输出上限，仅用于提示，实际账单以供应商为准。运行时可在「设置 → Agent 运行时」检查更新、安装兼容组件和回退。活动任务结束后切换运行时，组件安装前检查签名、公证、版本兼容和运行健康状态。

重大事件默认要求重要度不低于 75、置信度不低于 0.8，并具备两个独立来源或用户指定的权威来源。提醒默认关闭，开启后使用 23:00–08:00 免打扰、每小时 3 次、每天 10 次和 6 小时事件冷却。
